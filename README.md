# BITCLOTH

Primera versión del proyecto de tienda.

## Importante

Esta versión es un prototipo funcional de frontend.
Antes de vender realmente:

- Cambiar el login por autenticación real.
- Conectar Supabase/PostgreSQL.
- Añadir almacenamiento de imágenes.
- Crear checkout real.
- Integrar pagos Bitcoin mediante un procesador compatible.
- Añadir webhooks para confirmar pagos.
- Configurar dominio, HTTPS y políticas de la tienda.

## Ejecutar en una computadora

Requiere Node.js.

    npm install
    npm run dev

Después abre:

    http://localhost:3000

La contraseña temporal del prototipo es:

    CAMBIA_ESTA_CLAVE

NO uses esta contraseña en una tienda publicada.
